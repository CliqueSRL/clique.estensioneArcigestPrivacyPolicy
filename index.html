This extension processes XML invoice data locally in your browser to automatically fill supplier form fields on the target website. It does not upload XML contents or extracted form data to our servers.

1. What this extension does

Clique compilatore Arcigest allows you to paste or load an Italian electronic invoice XML file and automatically compiles supplier form fields on the target website. All parsing and form filling happen locally in your browser.

2. Data we process

The extension processes only the XML data you provide and the form values derived from that XML. This may include supplier details such as company name, VAT number, tax code, address, city, postal code, and province.

3. How we use the data

We use the data only to:

  • parse the XML invoice locally;
  • extract supplier information;
  • populate the relevant fields in the target web form;
  • show status and validation messages in the extension UI.

4. Data we do not collect

We do not send XML invoice contents or extracted form data to external servers. We do not sell user data. We do not use user data for advertising, profiling, analytics, or tracking. We do not intentionally collect personal data from users outside the browser session required for the extension to work.

5. Data storage and retention

The extension does not store XML invoice data or extracted form data on our servers. Any data processed by the extension is used locally and only for the time needed to complete the form-filling action. If you clear the page, close the tab, or use the extension’s clear function, the in-memory data used by the extension is removed from the current session.

We do not share XML invoice data or extracted form data with third parties, except where required by law. The extension does not use third-party advertising or analytics services.

Questa estensione elabora localmente nel browser i dati XML della fattura per compilare automaticamente i campi del form fornitore sul sito di destinazione. Non carica il contenuto XML né i dati estratti sui nostri server.

1. Cosa fa questa estensione

Clique compilatore Arcigest consente di incollare o caricare un file XML di fattura elettronica italiana e compila automaticamente i campi del form fornitore nel sito di destinazione. Tutta l’elaborazione e la compilazione avvengono localmente nel browser.

2. Dati trattati

L’estensione tratta soltanto i dati XML forniti dall’utente e i valori del modulo derivati da tale XML. Possono essere inclusi dati del fornitore come denominazione, partita IVA, codice fiscale, indirizzo, comune, CAP e provincia.

3. Come utilizziamo i dati

Utilizziamo i dati solo per:

  • analizzare localmente il file XML della fattura;
  • estrarre le informazioni del fornitore;
  • compilare i campi rilevanti del form web di destinazione;
  • mostrare messaggi di stato e di verifica nell’interfaccia dell’estensione.

4. Dati che non raccogliamo

Non inviamo il contenuto del file XML né i dati estratti del modulo a server esterni. Non vendiamo dati degli utenti. Non utilizziamo i dati per pubblicità, profilazione, analytics o tracciamento.
