This extension processes invoice XML data locally in your browser to fill fields in supported web forms. It does not upload XML contents or extracted data to our servers.

1. What this extension does

Clique compilatore Arcigest allows the user to paste or load an electronic invoice XML file and automatically fill selected fields in supported web forms. The extension works only in the browser and performs parsing and field population locally on the device.

2. Data processed by the extension

The extension processes only the data you provide in the XML invoice and the values derived from it for form completion. Depending on the page in use, this may include:

  • supplier data such as company name, VAT number, tax code, address, city, postal code and province;
  • invoice header data such as invoice progressive number, document date, total amount and note;
  • invoice line data such as description, taxable amount and tax amount.

3. How the data are used

The extension uses the data only to:

  • parse the XML invoice locally in the browser;
  • extract the data needed for the supported forms;
  • populate the relevant fields in the target website selected by the user;
  • show status and validation messages inside the extension interface.

4. Data that we do not collect

We do not send XML invoice contents or extracted form data to our servers or to any third-party servers controlled by us. We do not use analytics, advertising, profiling, tracking, or telemetry. We do not intentionally collect personal data outside the browser session needed for the extension to work. We do not use chrome.storage or other persistent storage mechanisms to save invoice contents or extracted form data.

5. Storage and retention

The extension does not store XML invoice data or extracted form data on our servers. Processing happens locally in memory and only for the time needed to complete the form-filling action. If you clear the form, close the tab, or use the extension’s clear function, the data used in the current session are removed from memory.

6. Sharing and third parties

We do not share XML invoice data or extracted form data with third parties. The extension does not use third-party advertising, analytics, or tracking services. Once the extension inserts data into the target website selected by the user, any subsequent processing of those data is governed by that website’s own privacy policy.

7. Permissions

The extension requests access only to the websites where it is designed to operate, so it can inject its interface and fill the form fields directly on those pages. The extension uses the minimum permissions necessary for this functionality.

8. Legal basis

To the extent that personal data are processed, the processing is carried out only to provide the extension’s functionality requested by the user and, where applicable, on the basis of the user’s explicit action in loading the XML and filling the form. This processing is limited to local execution in the browser. You should verify the exact legal basis applicable to your specific deployment before publishing.

9. Your rights

Where applicable under GDPR and other data protection laws, you may have the right to access, rectify, erase, restrict, or object to the processing of your personal data, and the right to data portability. You may also have the right to lodge a complaint with your local supervisory authority.

10. Changes to this policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated effective date.

Questa estensione elabora localmente nel browser i dati contenuti nell’XML della fattura per compilare i campi dei form web supportati. Non carica il contenuto XML né i dati estratti sui nostri server.

1. Cosa fa questa estensione

Clique compilatore Arcigest consente all’utente di incollare o caricare un file XML di fattura elettronica e compilare automaticamente alcuni campi nei form web supportati. L’estensione funziona esclusivamente nel browser e svolge l’analisi del file e la compilazione dei campi in locale, sul dispositivo dell’utente.

2. Dati trattati dall’estensione

L’estensione tratta soltanto i dati forniti dall’utente tramite il file XML della fattura e i valori derivati da tale file per la compilazione automatica dei form. A seconda della pagina utilizzata, possono essere trattati i seguenti dati:

  • dati del fornitore, come denominazione, partita IVA, codice fiscale, indirizzo, comune, CAP e provincia;
  • dati del documento fattura, come numero documento, data documento, importo totale e nota;
  • dati della riga fattura, come descrizione, imponibile e imposta.

3. Come utilizziamo i dati

Utilizziamo i dati solo per:

  • analizzare localmente il file XML della fattura nel browser;
  • estrarre le informazioni necessarie per i form supportati;
  • compilare i campi pertinenti nel sito web di destinazione scelto dall’utente;
  • mostrare messaggi di stato e di verifica nell’interfaccia dell’estensione.

4. Dati che non raccogliamo

Non inviamo il contenuto del file XML né i dati estratti a server nostri o a server terzi controllati da noi. Non utilizziamo strumenti di analytics, pubblicità, profilazione, tracciamento o telemetria. Non raccogliamo intenzionalmente dati personali al di fuori della sessione del browser necessaria al funzionamento dell’estensione. Non utilizziamo chrome.storage né altri meccanismi di memorizzazione persistente per salvare il contenuto degli XML o i dati estratti.

5. Conservazione dei dati

L’estensione non memorizza i dati XML della fattura né i dati del modulo estratti sui nostri server. L’elaborazione avviene localmente, in memoria, e solo per il tempo strettamente necessario a completare la compilazione del form. Se l’utente cancella il contenuto, chiude la scheda o utilizza la funzione di cancellazione dell’estensione, i dati presenti nella sessione corrente vengono rimossi dalla memoria.

6. Condivisione e terze parti

Non condividiamo i dati XML della fattura o i dati estratti con terze parti. L’estensione non utilizza servizi di terze parti per pubblicità, analytics o tracciamento. Una volta che l’estensione inserisce i dati nel sito web di destinazione scelto dall’utente, eventuali trattamenti successivi di tali dati sono disciplinati dall’informativa privacy di quel sito.

7. Permessi

L’estensione richiede accesso soltanto ai siti web sui quali è progettata per operare, così da poter inserire la propria interfaccia nella pagina e compilare direttamente i campi del form. L’estensione utilizza i permessi minimi necessari per questa funzionalità.

8. Base giuridica

Nella misura in cui siano trattati dati personali, il trattamento avviene esclusivamente per fornire all’utente la funzionalità dell’estensione richiesta dall’utente stesso e, ove applicabile, sulla base dell’azione esplicita dell’utente nel caricare l’XML e compilare il form. Il trattamento è limitato all’esecuzione locale nel browser. È opportuno verificare la base giuridica esatta applicabile al tuo specifico caso prima della pubblicazione.

9. Diritti dell’interessato

Ove applicabile ai sensi del GDPR e della normativa privacy vigente, l’utente può avere diritto di accesso, rettifica, cancellazione, limitazione o opposizione al trattamento dei propri dati personali, nonché diritto alla portabilità. L’utente può inoltre avere diritto di proporre reclamo all’autorità di controllo competente.
